## 📖 简介 / Overview

**ECC Skills 详细指南** 是一个面向 Claude Code 用户的交互式技能文档站，收录了 **270+ 项技能**，覆盖编程开发、数据库、AI 智能体、安全合规、运维部署等 **12 大模块**，支持技能搜索、关系图谱、依赖分析和搭配方案等多种视图，帮助开发者快速找到并组合所需技能。

**ECC Skills Detailed Guide** is an interactive skills documentation site for Claude Code users, featuring **270+ skills** across **12 major modules** including programming, databases, AI agents, security & compliance, and DevOps. It supports multiple views — skill search, relationship graph, dependency analysis, and combo recommendations — to help developers quickly find and combine the skills they need.

## 🚀 快速开始 / Quick Start

### 使用方法 / How to Use

1. **下载文件**：将 `ECC_Skills_详细指南Final.html` 保存到本地
   **Download**: Save the HTML file to your local machine

2. **打开浏览**：直接用浏览器打开 HTML 文件即可使用，无需服务器
   **Open**: Open the HTML file directly in your browser — no server required

3. **开始探索**：
   - 使用顶部搜索框查找特定技能
   - 通过左侧分类栏筛选模块
   - 切换视图模式（列表 / 关系图 / 依赖图 / 搭配方案）
   - 点击技能卡片查看详细说明

   **Start Exploring**:
   - Use the top search bar to find specific skills
   - Filter modules via the left sidebar
   - Switch view modes (Cards / Tree / Dependency / Combo)
   - Click skill cards for detailed descriptions
